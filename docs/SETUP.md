# Matjar El Kotobia — Developer Setup Guide

## Prerequisites
- XAMPP or Laragon (PHP 8.1+, MySQL 8.0+, Apache)
- Git
- VS Code (recommended)

## Quick Start
1. Clone/copy project to `htdocs/matjar_el_kotobia/`
2. Start Apache and MySQL
3. Import `sql/matjar_el_kotobia.sql` into phpMyAdmin
4. Update `config/database.php` if credentials differ
5. Update `config/constants.php` with your WhatsApp number
6. Visit `http://localhost/matjar_el_kotobia/`
7. Admin panel: `http://localhost/matjar_el_kotobia/admin/`

## Default Admin Login
- Username: `admin`
- Password: (set during initial DB setup)
